# HABITOMIC

**Short Description** : Habitomic is a website used to calculate the consistency of a specific task

## Main Feature
 - **Checkbox Task** : You can track your consistency by checking a task that you have done.
 - **Calendar One Month** : Shows the days on which you completed those tasks.
 - **CRUD For Task** : Create new task and delete
